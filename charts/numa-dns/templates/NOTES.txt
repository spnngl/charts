{{ include "numa-dns.fullname" . }} runs numa behind one Service.

In-cluster clients use the Service on port 53 (UDP and TCP):

  kubectl -n {{ .Release.Namespace }} run dig --rm -it --restart=Never --image=<an image with dig> -- \
    dig @{{ include "numa-dns.fullname" . }}.{{ .Release.Namespace }}.svc example.com

Check that the pods are ready:

  kubectl -n {{ .Release.Namespace }} get pods -l {{ include "numa-dns.selectorLabels" . | replace ": " "=" | replace "\n" "," }}

The dashboard and API listen on loopback in each pod and give full admin
access without a token to anything that reaches them; reach one pod with:

  kubectl -n {{ .Release.Namespace }} port-forward deploy/{{ include "numa-dns.fullname" . }} 5380:5380
