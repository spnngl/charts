{{- if not .Values.github.token }}

The GitHub token is read from the Secret `{{ include "ghcr-exporter.secretName" . }}`, key `{{ .Values.github.existingSecret.key }}`, which this release does not create. Without it the pod stays in
CreateContainerConfigError (`secret "{{ include "ghcr-exporter.secretName" . }}" not found`). Create it
(a classic personal access token with `read:packages`), or install with `--set github.token=<token>`:

  kubectl -n {{ .Release.Namespace }} create secret generic {{ include "ghcr-exporter.secretName" . }} \
    --from-literal={{ .Values.github.existingSecret.key }}=<token>
{{- end }}

The token is read at startup only: roll the pod after rotating it.

  kubectl -n {{ .Release.Namespace }} rollout restart deployment/{{ include "ghcr-exporter.fullname" . }}

Check the exporter:

  kubectl -n {{ .Release.Namespace }} get pods -l {{ include "ghcr-exporter.selectorLabels" . | replace ": " "=" | replace "\n" "," }}
  helm test {{ .Release.Name }} -n {{ .Release.Namespace }}
