{{ include "cloudflared.fullname" . }} runs {{ .Values.replicaCount }} cloudflared connector(s) in `{{ .Values.tunnel.mode }}` mode.

The chart never creates the tunnel Secret. It must exist in namespace {{ .Release.Namespace }}:

  kubectl -n {{ .Release.Namespace }} create secret generic {{ include "cloudflared.secretName" . }} \
    --from-file={{ include "cloudflared.secretKey" . }}=<path to the {{ ternary "token" "credentials.json" (eq .Values.tunnel.mode "token") }} file>

Secret changes are read at startup only: roll the pods after rotating it.

  kubectl -n {{ .Release.Namespace }} rollout restart deployment/{{ include "cloudflared.fullname" . }}

Check that connectors are registered:

  kubectl -n {{ .Release.Namespace }} get pods -l {{ include "cloudflared.selectorLabels" . | replace ": " "=" | replace "\n" "," }}
{{- if include "cloudflared.metricsService" . }}
  helm test {{ .Release.Name }} -n {{ .Release.Namespace }}
{{- end }}
